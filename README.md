## Before publishing

1. Replace every `[Company Name]` placeholder with the approved company name.
2. Replace `YOUR_EMAIL@example.com` in `index.html` with the business contact email you want studios to use.
3. Review the services and ensure the wording reflects capabilities currently offered. The site distinguishes current focus (research, validation and creator partnerships) from longer-term publishing ambitions.
4. Check all links and spelling.

## Publish with GitHub Pages

The intended repository is `laksuraj/suraj-lakshman.github.io`.

1. Open the repository on GitHub.
2. Upload `index.html`, `styles.css`, `script.js` and `README.md` to the repository root (replace the old files if appropriate).
3. Commit the changes to the `main` branch.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then save.
7. Check the deployment under the **Actions** tab. GitHub Pages may take a few minutes to publish.

The expected free address is `https://laksuraj.github.io/`.

## Notes

- No paid domain, hosting or third-party form service is required.
- The contact button uses a `mailto:` link. It opens the visitor's email application; it does not store form submissions.
- Google Fonts are used for typography. If external font loading is unavailable, the site falls back to system fonts.
- This is a static website and can be hosted directly on GitHub Pages.
